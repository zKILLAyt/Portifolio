# Gustavo Gomes | Portfólio

Portfólio estático de Gustavo Gomes, estudante de Engenharia da Computação e desenvolvedor. O site apresenta projetos, estudos de CyberSecurity e opções de contato direto.

## Conteúdo

- `index.html`: apresentação, stack, projetos e contato.
- `cybersecurity.html`: estudos e ferramentas locais de segurança.
- `assets/images/favicon.svg`: ícone do site.
- `assets/css/`: folhas de estilo do portfólio e da página CyberSecurity.
- `assets/js/`: navegação, filtros e interações executadas no navegador.

## Identidade visual

A interface usa uma paleta inspirada em Saturno: preto espacial `#090909`, preto profundo `#11100D`, grafite `#1C1A16`, marrom espacial `#33291E`, marrom dourado `#59452D`, dourado `#C5A46D`, areia `#D7C19A`, creme `#E9DDC5`, branco suave `#F5F1E8` e texto secundário `#A99F8E`.

## Funcionalidades

- Navegação responsiva e acessível por teclado.
- Filtros de projetos por categoria.
- Ferramentas locais de CyberSecurity, incluindo análise de texto, geração de hash, codificação Base64 e inspeção de cabeçalhos de uma URL informada pelo visitante.
- Contato por WhatsApp ou e-mail.
- Preferência por movimento reduzido respeitada.

O portfólio não possui backend, autenticação administrativa, banco de dados ou coleta de feedback. As ferramentas que precisam consultar um endereço externo só fazem isso quando a pessoa informa a URL na ferramenta de cabeçalhos.

## Como visualizar

Abra `index.html` ou sirva a pasta com qualquer servidor de arquivos estáticos. Não há instalação de dependências nem configuração de variáveis de ambiente.

## Projetos

Os cards apontam para repositórios do GitHub e incluem projetos front-end, back-end e estudos de segurança. A remoção do backend deste portfólio não altera os repositórios de projetos apresentados.
